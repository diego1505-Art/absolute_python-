#  absolute_python-

Bienvenue dans mon dépôt **absolute_python-** !

Ce projet regroupe mes exercices, cours, tests et différents projets réalisés lors de mon apprentissage de **Python**.

##  Contenu du projet

Le dépôt contient notamment :

*  Des fichiers Python (`.py`)
*  Des notebooks Jupyter (`.ipynb`)
*  Des fichiers PDF
*  Des fichiers CSV
*  Des fichiers de configuration (`.json`)
*  Des fichiers de logs (`.txt`)

###  Cours Python

Le dossier `python/1_Fichiers_cours_apprentissage_python/` contient différents cours et exercices autour des bases de Python :

* Installation et prise en main de l'environnement
* Les bases de Python
* Les conditions
* Les listes
* Les dictionnaires
* Les boucles
* Les fonctions
* Les librairies
* La gestion des erreurs
* L'ouverture et la manipulation de fichiers

###  Ateliers

Le dossier `python/2_fichiers_ateliers/` contient différents travaux pratiques et expérimentations, notamment autour de :
